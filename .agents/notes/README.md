# notes/ — 决策与依据记录

## 结构

- 每篇一个 `.md`，扁平存放，不建子目录。
- 命名：决策类 `YYYY-MM-DD-<主题>.md`；依据类可省日期。
- 第 3 行固定写状态行。

## 两类记录

- **决策类**：面对岔路口选了 A 不选 B。必须写 `## 替代方案`。
- **依据类**：勘察、评估、对照得出的结论，本身不含选择动作。可选写 `## 支撑的决策`。

## 状态值

`生效` / `被取代` / `已否决` / `已归档`。

- `被取代` 必须跟指针行。
- `已否决` 与 `已归档` 必须跟一句话理由。
- 归档就地标记，不移动文件。

## 查询

不建索引文件，用文件名检索。

写作规则见 [AGENTS.md](AGENTS.md)。
