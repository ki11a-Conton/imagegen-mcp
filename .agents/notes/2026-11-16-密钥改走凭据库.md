# 决策：密钥改走 DSH 凭据库，配置只留引用（2026-11-16）

状态：生效

## 问题

`install.ps1` 把 `CHATGPT2API_API_KEY` 作为字面量写进 profile 的 `cordis.patch.yml`。三个后果：

- 明文密钥落在一个「可导出、可分享、可版本化」的配置层里。`--dump-config`、截图、贴日志都会带出去。
- 每次重装 `Backup-PatchFile` 还会复制一份，密钥副本跟着扩散。
- 配置文件的职责是「说怎么挂」，不是「存凭据」。

顺带暴露了第二个问题：YAML 拼装、转义、块替换、备份全在 PowerShell 里，既进不了 `npm test`，
又反复踩 PowerShell 的语法细节（逗号绑定、`$Home` 只读）。

## 决策

1. **配置只写引用**：托管块固定输出 `expandTemplates: true` 与
   `CHATGPT2API_API_KEY: "${credential:CHATGPT2API_API_KEY}"`，明文分支直接删掉，不再保留。
2. **值进 DSH 凭据库**：`<DSH_HOME>/.credentials.yaml` 的 `refs`。那是 DSH 官方存储，
   仅本用户可读、改完自动热加载、不进环境变量。
3. **配置写入搬到 Node**：新增 `src/dsh-config.mjs`（纯函数）与 `src/setup.mjs`（CLI）。
   `install.ps1` 只探环境、拷文件、装依赖，然后调 `node src/setup.mjs`。
4. **旧格式自动迁移**：`setup.mjs` 认出托管块里的明文，把值搬进凭据库并改写配置。
   幂等：新格式再跑什么都不写。`--dry-run` 先看计划。
5. **重装不清洗已调好的配置**：没显式给的参数沿用上一版块里的值，用户自己加的环境变量原样带走。
6. **备份也不留密钥**：迁移后 `cordis.patch.yml.bak` 里那一行被替换成
   `<moved to credentials.yaml>`。回退点要留的是结构，值已经在凭据库里，重跑一次 setup 就补回来。
7. **启动自检兜底**：`apiKeyProblem()` 在值仍是 `${credential:…}` 时点名 `expandTemplates`，
   否则模板没展开只会表现为上游 401，查错方向完全错。

两处文件都按行手术，不做 YAML 解析：`cordis.patch.yml` 有 `!!js` 标签，通用解析器读不了；
`.credentials.yaml` 有 DSH 自己的注释，解析后重写会把注释冲掉。DSH 官方允许直接编辑该文件。

## 替代方案（否决）

- **保留明文，只做警告**：问题原样存在，且警告在安装时一闪而过，没人会改。
- **用 `!!js process.env.X` 引环境变量**：这是 DSH 文档里的老办法，可行但没有打码保护；
  且 MCP 的 stdio 子进程环境会洗掉名字含 `KEY|TOKEN|SECRET|PASSWORD` 的变量，
  「在外面 export 再传进去」这条路根本走不通，必须在配置里显式引用。
- **把值也写进 `cordis.patch.yml`，只是换个变量名**：等于没改。
- **整块交给 YAML 解析器重写**：`!!js` 标签解析不了，注释与用户条目也会被抹平。
- **把项目做成配置型 bundle（`dsh.bundle.patch` + plugin_manager 安装）**：这是 DSH 更正统的分发方式，
  但会改掉「支持任意 DSH_HOME、不依赖插件管理器」的定位，留作后续。
- **迁移时覆盖凭据库里的同名值**：会悄悄改掉用户已经换过的密钥。改为默认不覆盖，`--force` 才换。
- **迁移后保留原样的备份**：那等于把明文密钥又留了一份在 `.bak` 里，白折腾。改为备份也抹掉值。

## 影响

- 配置块结构变了：多出 `expandTemplates: true`，密钥从字面量变成模板。
  托管块标记沿用原样，所以旧安装能被认出来。
- 新增 `node src/setup.mjs` 这个可独立运行的入口，迁移不必重装。
- `install.ps1` 的 `-BaseUrl` / `-Model` / `-TimeoutMs` / `-OutputDir` 默认值改为空：
  不传就沿用上一版配置，首次安装才用内置默认。
- `AGENTS.md` 里两条 PowerShell 拼 YAML 的坑随代码一起消失，换成「别把 YAML 拼装搬回 PowerShell」。
- 真实装机后第一次跑会看到 `moved … → refs.CHATGPT2API_API_KEY`，之后都是 `unchanged`。
